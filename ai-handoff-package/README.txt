Stream Deck VK02 - AI Handoff Package

Bộ file này được tạo để gửi cho AI hoặc lập trình viên mới vào dự án.

Các file quan trọng:
- AI_HANDOFF.md
- src/main.js
- src/deck.css
- src/forest-pomodoro.css
- src/forest-tree-svgs.js
- src/todo-store.js
- index.html

Cách dùng:
1. Gửi toàn bộ folder này cho AI.
2. Hoặc chỉ gửi các file quan trọng trong folder.
3. Dùng AI_HANDOFF.md như file tóm tắt đầu tiên.

Lưu ý:
- Đây là bản copy để dễ chia sẻ.
- Mục tiêu là AI hiểu bối cảnh dự án, file nào quan trọng, và không phá layout/logic khi sửa.
